# R07 coefficient stability

**Status:** REGISTERED — NOT STARTED

**Experiment:** Reliability study R07

R07 descriptively measures whether the standardized coefficients of the accepted R02 ten-feature logistic reliability model retain their magnitude and sign under 2,000 similarity-group bootstrap refits.

R07 has no pass/fail performance gate and cannot change model selection. The exact analysis, reporting contract, completion rule, and fail-closed conditions are frozen in `audit/preregistration_amendment_10.md`. No R07 bootstrap refit had been run when this hypothesis was registered.
