# One-time sealed final evaluation

**Status:** REGISTERED — NOT STARTED

**Hypotheses:** H2, H3, H4

After every model, threshold, script, decision policy, and environment artifact is locked, one run will evaluate frozen v1 and the nominated final system on the untouched BRISC test membership. The classifier must pass G2, the segmenter must pass G3, and case reliability must pass G4. The three decisions remain separate; success in one cannot rescue failure in another.

This is internal-source confirmation because BRISC does not verify patient independence. It is not external or clinical validation. The test partition is not used for model selection and will not be reopened for a corrected candidate.
