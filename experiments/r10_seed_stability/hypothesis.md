# R10 estimator-seed stability

**Status:** REGISTERED — NOT STARTED

R10 descriptively evaluates whether the accepted R02 ten-feature standardized logistic reliability estimator changes when its estimator seed is set to the parent-preregistered values `7`, `21`, `42`, `84`, and `168` while all folds, features, cases, targets, and other parameters remain fixed.

R10 has no performance gate and cannot change model selection.
